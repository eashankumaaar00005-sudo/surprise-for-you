# A Secret Journey 💌

A premium, mobile-first interactive digital gift — dark rose-gold luxury,
built with **pure HTML, CSS and vanilla JavaScript** (no frameworks).

## Personalise it (edit only `config.js`)
1. `recipient` — the name of the person it's for.
2. `letter` — the words (default heartfelt letter included).
3. `gallery.photos` — add your images to `assets/photos/`.
4. `music.src` — add your song to `assets/music/`.

## Run it
It's fully static. Just open `index.html`, or serve the folder:

    npx serve .        # or: python3 -m http.server

Then open it on your phone for the full experience.
