# Music

Put your background song here (e.g. `song.mp3`) and set the path in
`config.js`:

    music: { src: "assets/music/song.mp3", startMuted: false }

Supported formats: .mp3, .m4a/.aac, .ogg.

The music starts on the first tap (when the letter is opened) — this is a
browser requirement, not a bug. A floating player in the bottom-right lets
you pause/resume any time.

Please only use music you have the rights to (your own, or royalty-free).
