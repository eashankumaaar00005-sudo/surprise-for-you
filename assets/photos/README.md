# Photos

Drop your images in this folder and reference them in `config.js`.

Expected by the default config:

    1.jpg  2.jpg  3.jpg  4.jpg  5.jpg  6.jpg

Any name works — just update the `gallery.photos` list in `config.js`.
Missing photos automatically show an elegant placeholder frame, so the
gallery always looks complete.

Tip: for best results use portrait images around 1080×1350px, optimised
(compressed) JPGs so the experience stays fast on mobile.
